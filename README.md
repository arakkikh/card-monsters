# Card Monsters

スマホ（縦画面）で遊ぶ、カードバトルゲームです。HTML・CSS・JavaScript だけでできていて、インストールは要りません。

- 遊ぶ：`index.html` を開く（GitHub Pages では https://arakkikh.github.io/card-monsters/ ）
- 攻略本：`guide.html`（作り直すときは `./build-guide.sh`）
- テスト：`tests.html` をブラウザで開く、または `./devtests/run.sh`（Mac）

## 音（BGM と効果音）

BGM も効果音も、外部の音楽ファイルなしで、コードで演奏しています（`audio.js` が演奏の仕組み、`music.js` が曲のデータ）。
オフラインでも鳴ります。音量・ミュート・iPhone の消音スイッチは、⚙ 設定 から変えられます。全部の曲は、設定の「🎵 曲と効果音を試聴する」で聞けます。

### 自分の音楽ファイルに差し替える

`assets/bgm/` フォルダに、下の表の名前で音楽ファイルを置くと、その場面ではコードの曲の代わりにそのファイルが流れます。
ファイルがない場面は、いつもどおりコードの曲が流れます。

| ファイル名 | 曲 | 流れる場面 |
|---|---|---|
| `home.mp3` | ホーム（メインテーマ） | ホーム・ステージ一覧・対戦履歴 |
| `deck.mp3` | デッキ・コレクション | デッキ一覧・デッキ編集・コレクション |
| `pack.mp3` | パック開封 | パックを開けている間と、出たカードの一覧 |
| `dungeon.mp3` | ダンジョン | ダンジョンの画面 |
| `puzzle.mp3` | パズル | パズルの一覧と、パズルを解いている間 |
| `event.mp3` | イベント | イベントの画面と、イベントの対戦 |
| `plain.mp3` | 平原 | 地形「平原」「見張りの丘」の対戦 |
| `forest.mp3` | 森 | 地形「森」「世界樹の根元」の対戦 |
| `volcano.mp3` | 火山 | 地形「火山」の対戦 |
| `sky.mp3` | 天空 | 地形「天空」「雷雲の頂」の対戦 |
| `swamp.mp3` | 毒沼 | 地形「毒沼」の対戦 |
| `castle.mp3` | 古城 | 地形「古城」「魔王の玉座」の対戦 |
| `lake.mp3` | 霧の湖 | 地形「霧の湖」「女王の濃霧」の対戦 |
| `boss1.mp3` | ボス戦 1章 | 1章のボス（はじまりの草原） |
| `boss2.mp3` | ボス戦 2章 | 2章のボス（霧の湖） |
| `boss3.mp3` | ボス戦 3章 | 3章のボス（茨の森） |
| `boss4.mp3` | ボス戦 4章 | 4章のボス（天空の砦） |
| `boss5.mp3` | ボス戦 5章 | 5章のボス（混沌の城） |
| `win.mp3` | 勝利のジングル | 対戦に勝ったとき（1回だけ） |
| `lose.mp3` | 敗北のジングル | 対戦に負けたとき（1回だけ） |
| `fanfare-epic.mp3` | ファンファーレ（エピック） | パックからエピックが出たとき（1回だけ） |
| `fanfare-legend.mp3` | ファンファーレ（レジェンド） | パックからレジェンドが出たとき（1回だけ） |

- ファイルは mp3 にしてください。ほかの形式（m4a など）にしたいときは、`audio.js` の `BGM_FILES` のファイル名を書き換えます。
- 場面の曲は、ファイルの終わりから頭へ戻ってくり返します。継ぎ目が目立たないように、ループ用に作られた曲を使うのがおすすめです。
- ファイルの曲には「戦況で足すパート」（消耗ダメージ・残りわずかのときに重なる太鼓など）は付きません。
- ジングル・ファンファーレのファイルは、くり返さず1回だけ流れます。数秒の短い音にしてください。
- ファイルが読めるのは、GitHub Pages やローカルのサーバー（例：`python3 -m http.server`）から開いたときだけです。`index.html` をファイルとして直接開いたときは、ブラウザの制限で読めないため、コードの曲になります。
- 置いたあと、ブラウザを再読み込みすると反映されます。
- 他人が作った音楽を置くときは、利用条件（ゲームに使ってよいか・公開してよいか）を確かめてください。
